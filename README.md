# 龍成 Portfolio

ホームページ・LP制作を行うフロントエンドエンジニア「龍成」のポートフォリオサイトです。

制作実績の一覧と担当範囲を掲載しています。フレームワークやビルドツールを使わず、HTML・CSS・JavaScriptのみで構成された静的サイトです。

## 主な機能

- 制作実績一覧のデータ描画
- スクロールに合わせた表示アニメーション
- PC・タブレット・スマートフォンへのレスポンシブ対応
- スマートフォン用ナビゲーション
- 日本標準時のリアルタイム表示
- 外部サイトおよびメールへの導線

## 使用技術

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts（Noto Sans JP / Noto Serif JP）
- Git / GitHub

パッケージのインストールやビルド作業は不要です。

## ローカルでの起動方法

リポジトリを取得し、プロジェクトのルートへ移動します。

```bash
git clone https://github.com/Ryuusei-git/new-portfolio.git
cd new-portfolio
```

Pythonの簡易HTTPサーバーを起動します。

```bash
python3 -m http.server 8000
```

ブラウザで次のURLを開きます。

```text
http://localhost:8000
```

終了するときは、サーバーを起動したターミナルで `Ctrl + C` を押してください。

> `index.html` を直接開くこともできますが、実際の公開環境に近い状態で確認するため、ローカルサーバーの使用を推奨します。

## ディレクトリ構成

```text
.
├── assets/
│   └── works/              # 制作実績一覧で使用する案件画像
├── data/
│   └── projects.js         # トップページの制作実績一覧データ
├── index.html              # トップページ
├── style.css               # トップページのスタイル
└── script.js               # トップページの描画・演出・ナビゲーション
```

## コンテンツの編集方法

### プロフィールや連絡先を変更する

トップページの文章、対応内容、使用技術、受付時期、メールアドレス、SNSリンクは `index.html` で編集します。

公開前に、次の仮リンクを実際の情報へ変更してください。

- `mailto:hello@example.com`
- Instagramの `href="#"`
- Xの `href="#"`

### 制作実績の一覧を編集する

`data/projects.js` の `window.PROJECTS` を編集します。一覧の表示順は配列の順番と同じです。

```js
{
  title: "案件名",
  role: "担当範囲",
  year: "2026",
  yearLabel: "二〇二六",
  image: "./assets/works/page-example-01.png",
  imageAlt: "案件画像の説明",
}
```

各項目の役割は次のとおりです。

| 項目 | 内容 |
| --- | --- |
| `title` | 一覧に表示する案件名 |
| `role` | 一覧に表示する担当範囲 |
| `year` | `<time>` 要素の機械可読な年 |
| `yearLabel` | 画面に表示する年 |
| `image` | 一覧画像のパス |
| `imageAlt` | 画像を説明する代替テキスト |

### 新しい制作実績を追加する

1. 縦長のページ画像を `assets/works/` に配置します。
2. `data/projects.js` に一覧用データを追加します。

案件データはJavaScriptでHTMLへ挿入されるため、管理者が確認した信頼できる文字列だけを登録してください。

## 画像の命名例

- ページ全体画像: `page-{slug}-01.png`

画像を追加したら、ファイル名の大文字・小文字を含め、データ内のパスと一致していることを確認してください。

## 公開前チェック

- 画像が欠けず、代替テキストが内容を説明している
- 外部サイトのURL、メールアドレス、SNSリンクが正しい
- PCとスマートフォンの両方でレイアウトを確認した
- メニューとスクロール演出が操作できる
- ブラウザの開発者ツールにエラーが出ていない
- 実績として掲載する画像・文章・外部サイトへのリンクに問題がない

## Gitでの基本的な更新手順

作業用ブランチで変更し、内容を確認してからコミットします。

```bash
git switch ryuusei
git status
git add README.md
git commit -m "Add project README"
git push -u origin ryuusei
```

ほかのファイルも変更した場合は、内容を確認して必要なファイルだけを `git add` してください。
